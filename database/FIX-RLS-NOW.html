⚡ Fix RLS - Copy & Paste SQL

This will fix Row Level Security policies on fighter_profiles table

1

Copy the SQL Below

Click the "Copy SQL" button to copy the entire SQL command to your clipboard.

GRANT USAGE ON SCHEMA public TO anon, authenticated; GRANT SELECT ON TABLE public.fighter_profiles TO anon, authenticated; ALTER TABLE public.fighter_profiles ENABLE ROW LEVEL SECURITY; DO $$ DECLARE r RECORD; BEGIN FOR r IN SELECT policyname FROM pg_policies WHERE schemaname = 'public' AND tablename = 'fighter_profiles' AND (cmd = 'SELECT' OR cmd = 'ALL') LOOP EXECUTE format('DROP POLICY IF EXISTS %I ON public.fighter_profiles', r.policyname); END LOOP; END $$; CREATE POLICY "Authenticated users can view fighter profiles" ON public.fighter_profiles FOR SELECT TO authenticated USING (true); CREATE POLICY "Anonymous users can view fighter profiles" ON public.fighter_profiles FOR SELECT TO anon USING (true); SELECT 'SUCCESS - RLS FIXED' as status, COUNT(*) as visible_rows FROM public.fighter_profiles;
2

Open Supabase SQL Editor

Click the button below to open your Supabase SQL Editor in a new tab:

🚀 Open Supabase SQL Editor

Or manually: Go to supabase.com/dashboard → Your Project → SQL Editor

3

Paste & Run SQL

  • In Supabase SQL Editor, click "New Query"
  • Paste the SQL you copied (Ctrl+V or Cmd+V)
  • Click "Run" button (or press Ctrl+Enter)
  • Wait for the results - you should see "SUCCESS - RLS FIXED" and a row count
4

Refresh Your App

Go back to your application and do a hard refresh:

  • Windows/Linux: Press Ctrl+Shift+R
  • Mac: Press Cmd+Shift+R

Fighters should now appear on your homepage! 🎉

✅ Expected Result: After running the SQL, you should see a result table with:
  • status column showing: "SUCCESS - RLS FIXED"
  • visible_rows column showing: the number of fighter profiles in your database
✅ Security Note: This keeps Row Level Security (RLS) enabled on the fighter_profiles table but adds permissive policies that allow both authenticated and anonymous users to read fighter profiles. This is the recommended approach - RLS stays enabled for security, but the policies allow public read access.
